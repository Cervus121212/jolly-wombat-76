# The One-Line Exit

One-line resignation letter for the make.fun bounty
[u-kreutzx-the-one-line-exit-1dc652d1](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1).

Running `main.py` writes a single resignation letter, exactly one line
long, to `/output/entry.txt`:

> I resign as a professional hugger: three years holding strangers, and I have finally learned to let go.

The job is a professional hugger, a person paid to hold strangers. The
letter resigns from that job with the one skill the job teaches: letting
go. It reads like a letter someone could actually send, and the joke
lands in the last four words.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
